# PRUDUCT SALES DATA ANALYSIS

---

## 📌 **Project Overview**

This project focuses on analyzing sales data to extract useful information about revenue, profit, profit margin, and units sold. Using a dataset containing multi-regional sales records, I developed a comprehensive dashboard to track key performance indicators (KPIs) and visualize their trends by month, country, segment, and product.

---

## ⚡ **Interactive Features**

*The dashboard is built to provide a 360-degree view of the business through three specialized perspectives:*
1. Revenue View: Analyze gross income and sales trends to identify high-value periods and markets.
2. Profit View: Focus on bottom-line performance, monitoring profit margins and cost efficiency (COGS).
3. Units Sold View: Track volume and inventory movement across different customer segments.

*Key Dynamic Elements:*
* Time Intelligence: Use the "Month" slicer to instantly compare performance across different periods.
* Contextual KPIs: All indicators (Total Revenue, Profit, Margin, Units Sold) and MoM (Month-over-Month) growth % automatically recalculate based on selected filters.
* Cross-Filtering: Click on any country or product to filter the entire dashboard and see specific performance metrics for that selection.

---

## 🛠️ **Technical Stack & Implementation**

* Tool: Microsoft Power BI
* Data Modeling: Integrated a financial dataset with custom measures.
* DAX / Calculations: * Implemented Time Intelligence functions to calculate Month-over-Month (MoM) growth. Dynamic switching between Revenue, Profit, and Volume metrics.
* Data Visualization: Used a mix of Clustered Bar Charts and Clustered Column Chart (Rankings), Line and Clustered Column Charts (Trends), Table and KPI Cards for a professional executive summary.

---

## 🔍 **Business Questions this Dashboard Answers**

*Instead of static insights, this tool is designed to help stakeholders answer:*
* Which segment is currently driving the most volume vs. the most profit?
* Are we maintaining a healthy profit margin even when revenue fluctuates?
* Which products are showing a downward trend in the current month compared to the previous one?

---

## 📂 **How to Explore**
* Open the .pbix file (if you have Power BI Desktop) to interact with the live filters.
